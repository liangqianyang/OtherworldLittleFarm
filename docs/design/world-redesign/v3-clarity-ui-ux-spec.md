# 世界 V3 整洁化 · UI/UX 视觉降噪规范与触控清单（v3-clarity-ui-ux-spec.md）

- **负责成员**: design-ui-designer（UI Designer）
- **日期**: 2026-11-19
- **本轮边界**: 只产出设计规格与实现要点，**不改代码**，由协调者统一实施。
- **任务背景**: 用户反馈「地图杂乱、眼花缭乱」。上轮审查已证明功能分区与几何无缺陷，本轮全部围绕**视觉可读性**。本文回答杂乱成因中「⑤ UI 层叠加」假设，并给出 V3 的 UI 降噪规范、逐屏规格与 §15 触控验证清单。
- **关联文档**: `docs/design/world-redesign/world-layout-v2.md`（V2 冻结几何）、`docs/design/world-redesign/layout-v2-ui-notes.md`（V2 UI 基线，**其 F1–F4 修已经代码核实落地**）、`docs/design/game-design-draft.md` §15/§17、`docs/design/design-improvement-proposal.md` §5（真机 14 条）。
- **验证状态声明**: 本文全部结论来自**代码静态核读 + 几何复算**，未跑编辑器与真机；标注「几何级复现」的条目为静态复算结论，非真机复现。

## 0. 结论先行（TL;DR）

**UI 层确实是「眼花缭乱」的独立成因之一，且是无需改地图几何就能先止血的部分。**
出生点（SPAWN 50,40，`TerrainData.ts:37`）一屏静态核读：**11 个可交互 UI 元素 + 6~8 个显示型 UI + 5~7 个世界空间浮动标签/标记 ≈ 22~26 个离散视觉元素**，叠在 6 种硬边地面纹理上；同屏 UI 色相 ≥8 种（金/奶白/警报红/紫/蓝/琥珀/绿/棕），铬面积（UI 覆盖）约 21%。人眼没有「休息区」，这是杂乱感的 UI 侧根因。

| # | V3 修正 | 一句话规格 | 效果 |
|---|---------|-----------|------|
| U1 | **撤除右列 4 钮**，并入「背包中枢」单入口 | 右列 卖粮/买种子/背包/图鉴（`WorldLiving.ts:192-198`）→ 只留 ⚙ + 🎒 两枚 88px 入口 | 右侧可交互 5→2 |
| U2 | **顶栏双行合一**为左上角单芯片 | WorldHUD+情报行 → 一枚状态芯片；夜袭情报转**瞬态 toast**（今晚有袭时常驻红徽标） | 常驻文字层 2→1 |
| U3 | **世界浮动文字纪律** | NPC 名牌只显示最近 1 个；路牌永久文字**删除**改情境交互；封印 200×200 装饰圈改为近距/战时显示 | 浮字层 ≤2 |
| U4 | **焦点模式**（roam/farm/fish/defense/decor） | 每模式一份 HUD 白名单，非白名单元素一律不渲染 | 同屏 UI 组 ≤4 |
| U5 | **铬语言与色相预算统一** | 全部面板同一底/描边/圆角；装饰色相 ≤2 + 功能色相 ≤3；指南针箭头改奶白体+彩尖 | UI 色相 8→≤5 |

**密度预算（V3 硬指标）**: 出生点一屏 可交互 UI ≤8（工具坞 6 槽计 1 组）、HUD「组」≤4、浮动文字层 ≤2、铬面积 ≤12%、装饰色相 ≤2。详见 §1.3 对照表与 §9 验收。

- **色相 ≥8**：金（坞/选中）、奶白（正文）、警报红（情报）、紫/蓝/琥珀（指南针三色）、绿/蓝（NPC tint 透出）、棕（右列钮/名牌/路牌/封印环）。

## 2. 全局设计规范 V3（基调：轻松温暖、像素风、横屏触控）

> 与 `layout-v2-ui-notes.md` §3 的关系：热区/安全边距/字号规则**全部沿用**，以下只列 V3 **新增或修订**项；未列出的继续有效。

### 2.1 铬语言统一（新增，U5 核心）

| 规则 | 值 |
|------|-----|
| 唯一面板样式 | 底 `#14161F @85%` + 描边 `#F2C14E @60%` 2px + 圆角 12（=现 ToolDock 语言，`ToolDockUI.ts:63-68` 全项目推广） |
| 唯一强调色 | `ui/gold #F2C14E`（选中/主按钮/芯片图标）；`ui/gold-hi #FFECA0` 仅选中描边 |
| 语义色 | `alert #FF6060`（夜袭/破坏性）、`success #7BC96F`（可收获/完成）——**只允许语义场景出现** |
| 名牌/路牌铬 | 统一为「半透明深底芯片」`#14161F@70%` 圆角 8、无描边、奶白字 20px（替换棕底/白描边两种旧样式） |
| 铬纪律 | 新 UI 一律引用 Token（§2.4 JSON），禁止再引入新的底色/描边色 |

### 2.2 色相预算（新增）

- **装饰色相 ≤2**：金 + 奶白（面板/按钮/文字）。任何纯装饰不得引入第三色。
- **功能色相 ≤3**：指南针 POI、alert、success。功能色只出现在「有信息含义」的最小面积上（8px 彩尖、12px 徽标点），**不做大面积实底**（取消指南针彩色箭头整体填充与彩色标签字，见 §4.1）。

### 2.3 触控与热区（沿用 V2，重申硬指标）

| 规则 | 值 |
|------|-----|
| 最小热区 | **88×88 设计px**（§17）；视觉最小 56px + 透明命中区补足 |
| 间距 | 相邻 ≥12px、纵向堆叠 ≥16px |
| 按下反馈 | ≤80ms（缩放 0.94 + 提亮 10%）；TOUCH_END 触发；滑出 12px 取消 |
| 边距 | 关键交互距屏边 ≥24px；异形屏 ≥ inset+8px；左右下 200px 拇指悬停区不放必读信息 |
| 正文下限 | **20 设计px**（§17）——本文据此判定名牌 16px/路牌 15px 不合规（§1.1） |

## 9. 验收标准（本规格落地后）

1. **密度**：出生点一屏 可交互 ≤8、HUD 组 ≤4、浮字层 ≤2、铬面积 ≤12%（C1 网格审计法）。
2. **色相**：装饰 ≤2 + 功能 ≤3；全项目 UI 仅一套面板铬（代码层：无绕过 UiTokens 的硬编码色，review 把关）。
3. **热区**：全部可交互 ≥88×88（地块网格按 V2 §5.2 例外）；正文 ≥20px（名牌/路牌修复后无例外）。
4. **功能不回退**：卖粮/买种子/图鉴/背包 从任意农田位置 ≤4 次触达；卖粮两段确认保留；夜袭信息 3 通道（红徽标/toast/睡前情境）至少 1 条可见。
5. C1–C8 + V2 V1–V16 真机全过；R1–R7 无未缓解项。
