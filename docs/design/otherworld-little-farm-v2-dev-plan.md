# 《异界小农场 2.0》分步开发实施计划

> 适用工程：Cocos Creator 3.8.8 · TapTap 小游戏优先 · 横屏 1280×720 · 国风奇幻绘本风（2.5D 斜俯视）
> 目标：按“先跑通 V1.0 主岛完整闭环并提审，再通过独立分包扩展雅居与群岛”的节奏稳步推进，每完成一个阶段都能真机可玩、可验收。

## 推进总览表

| 阶段 | 周期参考 | 核心目标 | 里程碑验收标准 | 
| ----- | ----- | ----- | ----- |

在动手前，先把原项目里“写得扎实且与美术无关”的纯逻辑直接搬进新工程，画面与旧地图彻底重写：

| 模块 | 处理方式 | 说明 | 
| ----- | ----- | ----- | 
| `EventBus.ts` / `SaveManager.ts` / `TimeSystem.ts` | **直接复用并微调** | 双槽 `.bak` 备份、版本迁移链、离线防回拨时间源已验证可靠，仅把日历改为 48 天（4 季×12 天、每 2 天一节气） | 
| `IPlatformAdapter.ts` / `LocalAdapter.ts` / `TapAdapter.ts` | **直接复用** | 平台隔离架构良好，继续把 TapTap 存档与“添加到桌面”收敛在适配层 | 
| `CombatLogic.ts` / `DefenseCore.ts` 与无头单测 | **参考架构重写扩展** | 保留“无头纯逻辑 + Node 单测”的工程习惯，扩展高台叠搭、相邻催化与便携灵植接口 | 
| `TerrainData.ts` / 旧像素贴图 / 旧黑框 UI 面板 | **彻底废弃** | 全面替换为国风手绘拼装地表、卷轴玉石 UI 与 2.5D 部件动画 | 

## 阶段 0：新工程底座、Bundle 规划与 TapTap 空包基线（第 1 周）

**本阶段目标**：把最容易后期爆雷的工程结构、分包边界和 TapTap 真机适配放在第一周解决。

* \[ \] **0.1 建立 Cocos Creator 3.8.8 新工程与目录规范**

  * 设计分辨率锁定 `1280×720`（Fit Height / 安全区自适应），关闭不必要的 3D 与物理模块以压缩引擎包体。

  * 提前建好 Asset Bundle 目录：`main`（首包：主岛核心与室内）、`bundle_dungeon`（异世界地牢）、`bundle_islands`（外岛与航海）、`bundle_decor`（节气家具包）、`bundle_audio`（国风音频）。

* \[ \] **0.2 搭建核心四基座与调试面板**

  * 迁移并跑通 `EventBus`、`TimeSystem`（48 天二十四节气模型）、`SaveManager`（版本号从 1 起步，预留 `farm / indoor / defense / dungeon / islands` 切片）、`DataManager`（统一 JSON 静态表加载器）。

  * 同步建立轻量 `DebugPanel`（仅开发版启用）：支持跳天、切节气、加物品/灵植、一键触发夜袭、打印存档，后续每个阶段都靠它提速。

* \[ \] **0.3 跑通首张统一数据表 Schema**

  * 先定好 `items.json`、`plants.json`（统一灵植总表，包含 `category: daily | amphibious | combo`、`seasons`、`solarTerms`、`defenseEffect`、`dungeonUse` 字段）、`fish.json`（含 `riverSegment`、`seasons`、`weather`）。

* \[ \] **0.4 TapTap 空包真机基线验证**

  * 用 `taptap-minigame-tools` 导出一版空壳包上真机测试：确认横屏无黑边、刘海屏安全区偏移正确、本地存储读写正常，记录初始首包体积。

## 阶段 1：国风绘本主岛、智能操控与核心种田闭环（第 2\~3 周）

**本阶段目标**：先用少量高品质国风手绘样板素材，把“站在主岛上逛一圈、开荒、种地、卖钱”的手感做到让人眼前一亮。

* \[ \] **1.1 确立首批国风美术样板与图集规范**

  * 产出 V1.0 主岛首批手绘资产：柔光青草/青石板/肥沃土壤可平铺块 + 过渡贴片、河流浅滩水波动画、主宅外观、古碑封印门、秘境石门、3 种树木/岩石开荒物件、首批 6\~8 种灵植（含幼苗/成长/成熟三态）。

  * 制作主角轻量部件动画（站立、行走、挥工具、翻滚），脚底统一配柔和椭圆投影，建立 `Y-Sort` 遮挡与树冠半透明淡出。

* \[ \] **1.2 搭建主岛大地图与三阶开荒边界**

  * 按固定主岛布局摆出居住庭院、初始熟田、三阶开荒荒地（一阶杂草枯木 / 二阶铁木青岩 / 三阶古木灵晶）、三段河流（上游寒溪、中游荷塘、下游入海口）、北侧封印防线与南岸废弃码头地标。

  * 实现工具等级校验：初始斧镐可清一阶荒地并直接释放新耕地；二/三阶给出清晰提示（需玄铁/灵火升级工具）。

* \[ \] **1.3 实现精美卷轴 UI 与单手智能主行动键**

  * 按国风卷轴与玉石圆钮规范制作主界面 HUD：左上角紧凑节气金卷（节气+天数+天气+金币）、右上角小圆钮（背包/图鉴/设置）、右下角智能主行动键（随最近可交互目标自动切换“浇水/收获/砍树/抛竿/进屋/对话”）。

  * 实现耕地长按连片作业（浇水/播种/一键收获），确保主界面视觉留白 ≥ 85%。

* \[ \] **1.4 跑通 48 天节气种田与金币闭环**

  * 接入普通作物（按大季节 12 天窗口）与节气灵种（按对应节气 2\~4 天窗口，错过次年返场）规则。

  * 接入出货箱/商店买卖、过夜结算与离线冷启动生长（上限封顶、作物只长不枯）。

## 阶段 2：室内雅居、厨房灵膳与分河段钓鱼（第 4\~5 周）

**本阶段目标**：让“家”真正活起来，同时把钓鱼、烹饪、NPC 与日常祝福串成一条温暖的生活链。

* \[ \] **2.1 搭建独立室内场景与网格装扮系统**

  * 靠近家门无缝切换至 2.5D 半剖室内场景（卧房 + 初始小土灶）。

  * 实现基础网格吸附摆放模式：家具占格校验、点选/拖动分离、撤销与保存至 `indoor` 存档切片；制作 10\~12 件首批国风家具与 1 套节气主题套装。

  * 接入“居室舒心度”计算：达到阈值或凑齐套装，次日清晨自动赋予温和祝福（如钓鱼判定放宽、地牢首层多 1 个宝箱）。

* \[ \] **2.2 实现厨房烹饪（灵膳、鱼汤与茶饮）**

  * 点击室内灶台打开卷轴式食谱界面：首批配置 8\~10 道菜（涵盖日常体力恢复、地牢移速/无敌帧/减耗蓝鱼汤、外岛预留抗性茶饮）。

  * 灵膳成品可装备到地牢快捷槽或在出门前食用生效。

* \[ \] **2.3 实现三河段×季节钓鱼生态**

  * 在上游寒溪、中游荷塘、下游入海口分别配置垂钓点与差异化鱼池表（首批 12 种鱼，覆盖四季与晴/雨天气）。

  * 实现全屏单点 QTE 钓鱼（咬钩窗口 ≥ 350 ms、水花+音效+震动提示、失败零惩罚），并支持将稀有鱼放进室内鱼缸活养。

* \[ \] **2.4 接入 4 位核心 NPC（陆伯、江老、玄墨、阿棠）**

  * 使用轻量化 JSON 对话脚本 + 条件标记，不做臃肿任务框架：陆伯卖种子与农谚、江老卖鱼饵与河段传闻、玄墨负责封印预告、阿棠定期来访卖稀有灵种与家具图纸（并埋下修缮码头的对话钩子）。

## 阶段 3：异世界元气地牢与随身灵植（第 6\~7 周）

**本阶段目标**：做出爽快、有记忆点的国风《元气骑士》体验，并让地牢产出强力反哺农场与二阶开荒。

* \[ \] **3.1 实现战斗 HUD 自动切换与核心动作手感**

  * 进出地牢自动切换主岛单键 UI 与双拇指战斗 UI（左动态摇杆 + 右攻击、翻滚、切武器、便携灵植快捷槽）。

  * 打磨战斗基础手感：自动瞄准与目标粘滞（约 0.6\~0.7 s）、0.22 s 翻滚无敌帧、受击顿帧与白色闪白、对象池（NodePool）管理子弹与怪物。

* \[ \] **3.2 构建“幽篁古墟”房间链与首领战**

  * 搭建 `bundle_dungeon` 分包，制作 5\~7 房手工模板 + 随机怪物/宝箱变异（入口安全房 → 探索战斗房 → 中点撤离阵抉择 → 精英/宝箱房 → 关底首领房）。

  * 制作 4\~5 种滑稽奇幻国风小怪（墨灵、符纸傀儡、竹精、远程符师）与 1 个机制清晰的首领。

* \[ \] **3.3 实装四大派系首批 8 把国风武器 + 便携灵植系统**

  * 近战格挡系（青竹剑、镇魂折扇，可斩碎敌方弹幕）、远程弹幕系（连发符箓枪、机关诸葛弩）、激光法器系（八卦聚光镜、雷纹灵杖）、灵植奇门系（荆棘藤鞭 + **随身便携灵植**）。

  * 实装玩家携带自家成熟的雷火薯（丢出当手雷，炸怪与暗墙）**和**穿云笋盆栽（落地扎根变临时炮台）进本，并支持进本前用作物给武器临时附魔元素词条。

* \[ \] **3.4 跑通地牢反哺闭环**

  * 地牢宝箱与首领稳定产出玄铁矿（用于升级斧镐开二阶荒地）、异界稀有灵植种子、武器图纸与家具蓝图。

## 阶段 4：封印防线、灵植叠搭连携与夜战闭环（第 8\~9 周）

**本阶段目标**：把最具差异化的“奇思灵植叠搭与相邻催化守家”做扎实，同时守住“前期零压、失败不清档”的温暖基调。

* \[ \] **4.1 接入“农田灵气度”解锁机制与前夜情报**

  * 开局封印完全稳固；当玩家开荒达标并收获首批成熟作物后，由玄墨唤醒首次入侵，之后每 4\~6 天触发一次预告型夜袭。

  * 入侵前 1\~2 天，玄墨在卷轴情报卡中给出不完全提示（怪种口味、弱点与本次主攻裂隙口）。

* \[ \] **4.2 实现固定可扩建防线与“宿根再生”**

  * 北侧封印防线格永久保留玩家布置；所有种在防线的灵植具备**宿根再生**（爆炎土豆炸后留根，15 秒或下一波自动再生，不永久消耗种子）。

  * 随封印修复度推进，防线从 1 条主通道逐步解锁侧路与浅滩水路。

* \[ \] **4.3 实现 2.5D 高台叠搭、相邻催化与节气地块增益**

  * **高台叠搭**：撑天竹/浮空莲台成熟后标记为 `canStack = true`，允许在其上叠种穿云笋/莲子弓手；渲染上将射手 Y 轴抬升半格并补投影，逻辑赋予“射程 +30%、可对空、免近战啃咬”。

  * **相邻催化**：每当防线布置变动时扫描四邻格，自动激活连携（如炎椒藤邻接射手→箭矢带灼烧、聚水荷邻接引雷草→范围感电链），并用柔和连线光效提示玩家配合生效。

  * **节气天时 + 鱼饵 + 亲自参战**：雨天低洼格增幅雷系、霜降河岸格带减速；支持波间调整阵台、放河鱼诱饵引怪，且玩家可手持武器下场补刀。

* \[ \] **4.4 实现柔和结算与归因战报**

  * 首败免罚；后续部分失守按漏怪扣少许祭坛耐久（可花少许金币修复）或少量果蔬，弹出“哪条路漏了哪种怪”的可视化归因战报。

## 阶段 5：V1.0 音画打磨、包体压测与 TapTap 提审上线（第 10 周）

**本阶段目标**：打磨精品独游质感，守住 TapTap 小游戏所有技术与合规红线，完成首测上架。

* \[ \] **5.1 接入动态国风音乐、材质音效与微动态**

  * 接入 `bundle_audio`：主岛古筝竹笛、地牢琵琶战鼓、夜战低沉编钟（全部 64\~96 kbps 单声道 MP3），加上草地/石板/木桥脚步声与灵植成熟清脆提示音。

  * 增加低开销微动态：水波闪光、四季飘落粒子（花瓣/萤火/落叶/雪花）、傍晚屋檐灯笼自动亮起。

* \[ \] **5.2 10 分钟无压新手引导链**

  * 用自然光圈与 NPC 短对话串起首轮体验（砍第一棵树→种第一块地→进屋做第一碗菜→河边钓第一条鱼→探一次幽篁古墟），不做锁屏黑遮罩教学。

* \[ \] **5.3 性能、包体与真机验收**

  * 全图集压缩（WebP / 8-bit PNG 视平台兼容性实测），不内置完整中文 TTF 字体。

  * 真机核验红线：**首包 ≤ 4 MB、整包 ≤ 30 MB、冷启动 < 5 秒、同屏战斗稳定 30\~60 fps、切后台 `onHide` 强制落盘不丢档**。

* \[ \] **5.4 TapTap 合规与提审准备**

  * 接入必接能力「添加到桌面」；检查无内购/广告残留位；准备游戏内容说明、隐私说明（如实声明本地存档）并按流程推进前置备案与自测提审。

## 阶段 6：V1.1 \~ V1.3 后续内容扩展路线（独立分包热扩）

V1.0 跑通并拿到真实玩家反馈后，按以下顺序逐个上新，绝不改动底层架构：

* \[ \] **V1.1 雅居与灵宠篇**：住宅扩建（独立厨房 + 茶室）、`bundle_decor` 首批 4 套节气/节日家具、轻量国风灵宠（自动拾取掉落物）、4 位 NPC 个人故事线。

* \[ \] **V1.2 扬帆出海篇**：阿棠码头修缮任务、海上甲板轻遭遇事件、`bundle_islands` 首座极端天气外岛（**赤焰礁**火山岛）+ 丹炉地宫新地牢。

* \[ \] **V1.3 群岛与终局篇**：**玄霜屿**（暴风雪）与**青瘴泽**（潮汐浓雾）两座外岛、归墟玄殿终局地牢、老花匠**四季灵棚**（解锁反季节培育）与全图鉴二周目年鉴。
