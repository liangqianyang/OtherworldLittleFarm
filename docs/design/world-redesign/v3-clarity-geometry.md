## 结论先行

**V3 = 「一条主干、一河一湖、五块大陆区、草地统治」。** 尺寸 96×80 不变；地面纹理从「6 底色 0 变体 0 过渡」改为「6 底色 + 0 新色 + ≤6 过渡条 + 草地同色变体」；路网从 9 段 2 宽环网（约 298 格铺装）改为 **1 主干 + 3 支路**（约 190 格，含广场/台地）；分区从「6 矩形互相咬合/重叠 + 0 边界物」改为「6 矩形零重叠 + 树篱/树线边界物」。出生屏地面纹理 4 种→**2 种**，铺装 69%→**27%**，草地 31%→**71%**。不新增任何玩法系统，新增美术 ≤2 个精灵 + 6 张过渡条 + 草地变体（明度微差，非新色）。

## 1. 总尺寸论证：96×80 保留

- 各区面积合计 4452 格 = 58%，剩余 42% 为河/湖/缓冲带/留白——扩图或缩图都不改善「密度」问题（问题在分布不在总量）。
- 缩到 88×72 可省 ~20% 首次生成开销，但会挤压 defense/fishing 缓冲带，违反 R7；扩大则违反 MVP 产能。
- terrainSize 守卫：尺寸不变使存档基线重建逻辑保持同一分支（降低 Q4 回归面）。
