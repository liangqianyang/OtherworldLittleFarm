# 首个可玩版本

## 一句话概念

经营一座连接异世界封印的温馨农场；玩家种植和钓鱼，进入独立探险地图收集物资，并在怪物入侵时守护家园。

## 核心循环

农场准备 → 探险收集 → 建造与布置 → 封印入侵 → 获得奖励并继续经营。

## 首个试玩切片

- 一块农场地图、一个钓鱼点和一间预布置可参观的房间（可编辑摆放延后）。
- 四种普通作物、一种稀有作物，以及基础浇水、施肥和收获。
- 一张平面 + 遮挡的探险地图（手工房间链 5-7 房；真实高台/楼梯延后）。
- 三种普通怪物和一场分波次的封印防守。
- 两名 NPC：园艺师与守门人。
- 基础物品图鉴、存档和触屏操作。
- 首个可玩版本不接广告和内购，先验证核心循环与 TapTap 构建。

## 玩法边界

- 农场、探险和防守是独立区域，通过入口或事件切换。
- 首版通过 2D 像素遮挡（y 排序 + 遮挡淡出）表达层次感；真实高低层/楼梯延后，启动第二张探险图前先做 3 天 spike 验证。
- 防守失败按破坏程度损失作物或材料，保留核心进度，避免整片农场清空。
- 节气与节日采用游戏内循环日历；限时种子与家具后续周期返场。
- 收集、布置、NPC 关系和封印剧情共同提供长期目标。
