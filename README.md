# 异界小农场 2.0 | OtherworldLittleFarmV2

全新 Cocos Creator 3.8.8 独立工程（不含任何旧版像素脚本），已完成 **阶段 0** 全部底座搭建并预置好 `launch.scene`。

## 3 步直接运行
1. 解压本文件夹到任意干净目录（不要放进老项目）。
2. 打开 **Cocos Dashboard** → 点击「打开」导入 `OtherworldLittleFarmV2` 文件夹（选择 Cocos Creator **3.8.8**）。
3. 编辑器中打开 `assets/scenes/launch.scene`，直接点顶部「运行预览」：
   - 顶部会显示青瓷背景与 `DBG` 调试条（已自动挂载 `GameApp` 与 `DebugPanel`）。
   - 点 `DBG` 展开后可直接测试 `+1天 / +6天 / +100金 / +全灵植 / 印存档 / 重置档`，控制台会输出 `DataManager` 校验通过与当前节气状态。
