## 1. 坐标与单位约定

- 设计分辨率 **1280×720**，`ResolutionPolicy.FIXED_HEIGHT`（`WorldSpike.ts:63`）；屏幕宽 >1280 的设备向两侧扩展。
- 本文所有坐标为 **屏幕中心系**（原点=画面中心，x 向右、y 向上，单位=设计 px），与现有代码约定一致（`JoystickController.ts:49`）。
- 世界 px → 屏幕 px 比例 = **1:2**（主相机 `orthoHeight=180`，视口 640×360 世界px，`WorldSpike.ts:79-83`）。
- 热区（hit）= 触摸响应区域；视觉（visual）= 绘制区域。**标准：可交互元素热区 ≥88×88 设计px**（game-design-draft.md §17）。

## 3. 基础规范（轻量版）

### 3.1 热区与触控

| 规则 | 数值 |
|------|------|
| 最小热区 | 88×88 设计px（≈44-48dp，iOS/Android 双标准，§17） |
| 视觉/热区分离 | 像素小按钮视觉 ≥56px + 透明命中区补足 88px |
| 相邻可点元素间距 | ≥12px；纵向堆叠间距 ≥16px |
| 按下反馈 | ≤80ms 内出现（缩放 0.94 + 提亮 10%）；动作在 TOUCH_END 触发，滑动超出 12px 视为取消 |
| 多点触控 | 移动（左手）与按钮（右手）并发互不抢占；按钮 claim 触点后摇杆不得吞 END（现有 sibling 修复延续，`WorldSpike.ts:218-224`） |

### 3.2 安全边距与遮挡

| 区域 | 规则 |
|------|------|
| 基础边距 | 关键交互/信息距屏边 ≥24 设计px |
| 异形屏 | 关键交互距物理边缘 ≥ inset+8px（§17 盲区条款）；横屏刘海在左/右短边 |
| 横握遮挡 | 左下/右下角约 200px 半径为拇指悬停区：**不放必读信息**；可放瞬时点按按钮但需 88px 热区 |
| 边缘锚定 | 右上（⚙/背包）、右下（工具坞）、左下（摇杆区提示）按 `view.getVisibleSize()` 锚边重算，不写死 ±(640−N)（MVP 最小集：⚙ 与工具坞两处） |
