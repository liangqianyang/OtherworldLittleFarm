## 7. 存档迁移守卫（实施版）

老档 RLE 是 128×96=12,288 格，新图 7,680 格——直接截断解码会得到垃圾地形且不报错。实施取 `terrainSize` 守卫（未升 SAVE_VERSION）：

- `GameApp.persist` 写 `world.terrainSize = MAP_W*MAP_H`（SaveManager WorldSave 加可选字段）；
- `WorldSpike.start` 解码前校验 `worldSave.terrainSize === MAP_W*MAP_H`，不等 → `generateBaseline()` 重发基线。

效果与 impl-spec §5 的 SAVE_VERSION 4 方案等价（旧 RLE 作废），代码更少；farm plots 按 index 映射零损失，其余切片不动。

## 9. 不变式（后续改动必须遵守）

1. 任何新地物落点先跑 `tools/validate-layout-v2.py`，红一行即落盘回滚。
2. 地标坐标只认本文 §4 表；不再在机制文档里新增坐标字面量。
3. 河道段表是数据（§2），改河=改表+重跑校验，不改 generateBaseline 结构。
4. 副本门/祭坛必须在北主路（northV/altarH）可达轴上——这是"可见性达标"的几何前提。
